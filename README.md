# auto-attendance

🏃‍♀️ 런닝크루 출석체크 페이지입니다 🏃‍♀️

크루장이 나온 사람만 찍으면 구글 시트에 기록되고, 포인트와 경고가 자동 계산됩니다.

## 빠른 시작

```bash
npm install
npm run dev        # http://localhost:3000
```

환경변수가 없으면 **목 데이터**로 돌아가서 설정 없이 화면을 볼 수 있습니다.
목 데이터는 오늘을 기준으로 만들어지므로, 지난주 기록 수정과 확정된 달 잠금을 바로 눌러볼 수 있습니다.

## 화면

- `/` — 출석 체크. 날짜를 과거로 바꾸면 그날 기록을 불러와 수정합니다.
  잘못 찍었으면 같은 버튼을 다시 눌러 취소하고 저장하면 됩니다
- `/solo` — 혼뛰 후기 입력. 그 달 인정 점수를 바로 보여줍니다
- `/summary` — 월별 포인트·경고·퇴출 대상과 판정 근거 (시트가 계산하지 않는 부분)

**시트가 원본입니다.** 앱은 입력 도구이고, 시트를 직접 고쳤으면 상단 **동기화**
버튼으로 다시 읽어옵니다.

## 아직 안 된 것

- **배포.** Vercel 설정 절차는 기획서 9절에 있고, 아직 올리지 않았습니다
- **로그인이 없습니다.** URL 을 아는 사람은 누구나 출석을 고칠 수 있습니다
- **월 확정(잠금)** 은 시트에 해당 개념이 없어 미연동입니다

**시트의 `최종 합산` 과 앱의 집계는 다릅니다.** 정기러닝·혼뛰 가산과 경고 판정은
앱에서만 계산합니다 (월별 탭에 열을 추가하면 기존 수식이 깨지기 때문). 기획서 10절 참고.

자세한 내용은 기획서 9절을 보세요.

## 기술

Next.js 15 (App Router) · TypeScript · CSS Modules · Vitest

데이터는 기존 크루 시트(`런나잇_출석포인트`)의 월별 탭에 그대로 들어갑니다.
주간 20점 상한과 합산·랭크는 **이미 시트 수식**이라 앱은 날짜 셀에 값만 씁니다.
경고·퇴출 판정처럼 시트가 계산하지 않는 부분만 앱에서 계산하고,
그 규칙 숫자는 [`src/lib/scoring.ts`](src/lib/scoring.ts) 의 `RULES` 에 있습니다.
