# auto-attendance

🏃‍♀️ 런닝크루 출석체크 페이지입니다 🏃‍♀️

크루장이 나온 사람만 찍으면 구글 시트에 기록되고, 포인트와 경고가 자동 계산됩니다.

## 빠른 시작

```bash
npm install
npm run dev        # http://localhost:3000
```

환경변수가 없으면 **목 데이터**로 돌아가서 설정 없이 화면을 볼 수 있습니다.
목 데이터는 오늘을 기준으로 만들어지므로, 지난주 기록 수정과 확정된 달 잠금을 바로 눌러볼 수 있습니다.

## 화면

- `/` — 출석 체크. 날짜를 과거로 바꾸면 그날 기록을 불러와 수정합니다
- `/summary` — 월별 포인트·경고·퇴출 대상과 판정 근거

## 문서

**[docs/기획서.md](docs/기획서.md)** 에 규칙, 데이터 구조, 설계 결정과 그 이유, 구글 시트 연결 절차가 전부 있습니다.

## 아직 안 된 것

- **구글 시트 실제 연결이 검증되지 않았습니다.** 코드는 있지만 인증 정보가 없어 읽기/쓰기를 실측하지 못했습니다
- **로그인이 없습니다.** 배포하면 URL을 아는 사람은 누구나 출석을 고칠 수 있습니다

자세한 내용은 기획서 9~12절을 보세요.

## 기술

Next.js 15 (App Router) · TypeScript · CSS Modules · Vitest

데이터는 구글 시트에 저장하고, 점수는 저장하지 않고 매번 계산합니다.
규칙 숫자는 [`src/lib/scoring.ts`](src/lib/scoring.ts) 의 `RULES` 에 모여 있습니다.
